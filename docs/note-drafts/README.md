# note投稿ドラフト集

Uranai Gardenへ読者を自然に連れてくるためのnote用ドラフトです。

使い方:

1. noteで「投稿」を開く
2. 使いたい `.md` ファイルの本文をコピーして貼る
3. タイトル、本文、ハッシュタグを整える
4. 公開後、アクセスが増えた記事のテーマをUranai Garden側でも増やす

投稿ペースの目安:

- 最初の2週間: 週3本
- その後: 週1〜2本
- 伸びたテーマはサイト側の記事や占いページへ追加

注意:

- 占いはエンタメ目的であることを本文内に入れる
- 不安を煽らない
- 医療、投資、法律、人生の重大判断を断定しない
- PRや広告を入れる場合は「PR」「広告」を明記する
